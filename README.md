# Referral Reward Calculator

GitHub Pages-ready calculator using plain HTML, CSS and JavaScript.

## Inputs
- Product price
- Direct referrals per user
- Number of lines
- Reward for each of lines 1–7

## Status
UI and network structure are ready. The final cascading repeat-purchase simulation is intentionally pending until the exact business rules are finalized.

Open `index.html` directly or publish the repository with GitHub Pages.
